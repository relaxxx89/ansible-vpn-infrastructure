# VPN-инфраструктура на Ansible

Ansible-проект для управления личным VPN-сервером на Debian 12.

Автоматизирует настройку сетевой безопасности, восстановление 3x-ui из резервных копий и управление TLS-сертификатами.

## Технологии

- **Ansible** — управление конфигурацией сервера.
- **Debian 12** — операционная система.
- **UFW** — настройка сетевого экрана.
- **3x-ui / Xray-core** — управление VPN-подключениями.
- **VLESS REALITY** — основной VPN-протокол.
- **Certbot / Let's Encrypt** — выпуск и продление TLS-сертификатов.
- **systemd** — управление сервисами.

## Возможности

- Настройка UFW с помощью Ansible.
- Управление разрешёнными TCP/UDP-портами.
- Восстановление 3x-ui и SQLite-базы из локальной резервной копии.
- Управление systemd-сервисом 3x-ui.
- Установка Certbot и включение автоматического продления сертификатов.
- Deploy-hook для передачи обновлённых сертификатов в 3x-ui.
- Повторное применение конфигурации без переустановки существующих компонентов.

Каталог `private/` содержит локальные резервные копии и исключён из Git.

## Требования

- Debian 12 на целевом сервере.
- Ansible на управляющем компьютере.
- SSH-доступ к серверу.
- Python 3 на сервере.
- Коллекция Ansible `community.general`.
- Резервная копия существующей установки 3x-ui.

Установка коллекции:

    ansible-galaxy collection install community.general

## Настройка

Скопировать примеры конфигурационных файлов:

    cp inventory/hosts.ini.example inventory/hosts.ini
    cp inventory/group_vars/vpn.yml.example inventory/group_vars/vpn.yml

В `hosts.ini` указать IP-адрес сервера, SSH-пользователя и путь к ключу.

В `vpn.yml` указать домен и параметры запуска сервисов.

Для восстановления 3x-ui необходимо заранее подготовить локальный каталог `private/` с файлами существующей установки.

## Развёртывание

Проверка синтаксиса:

    ansible-playbook --syntax-check playbooks/deploy.yml

Применение конфигурации:

    ansible-playbook playbooks/deploy.yml

## TLS-сертификаты

Для выпуска и продления сертификатов используется Certbot.

Предусмотрен deploy-hook, который:

1. Получает обновлённые сертификаты из каталога Let's Encrypt.
2. Копирует их в каталог, используемый 3x-ui.
3. Перезапускает 3x-ui при изменении сертификатов.

Первоначальный выпуск сертификата выполняется отдельно после настройки DNS и доступа по TCP/80.

Само наличие deploy-hook в проекте не означает, что он уже установлен на целевом сервере.

## Безопасность

- Приватные SSH-ключи и TLS-ключи не публикуются.
- Базы данных и резервные копии исключены из Git.
- Реальные IP-адреса и домены вынесены в локальные настройки.
- Панель управления 3x-ui не открывается для публичного доступа.
- Доступ к панели предусмотрен через SSH-туннель.
- Правила UFW управляются через Ansible.

## Ограничения

Проект предназначен прежде всего для восстановления существующей VPN-инфраструктуры.

Это не готовый установщик 3x-ui с нуля: для первоначального развёртывания требуются резервные копии.

Автоматизация выпуска первоначального TLS-сертификата и резервного копирования пока не реализована.
